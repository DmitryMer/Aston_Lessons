Пояснения: 1) Компонент Form родительский относительно дочернего Child, в компоненте Form прокидывается как пропс в дочерний Child в Button. 
2) В дочернем Child через метод handleChildAction передается значение стейта в родительский компонент Form через свойство onAction, далее в методе handleChangeState с помощью входного свойства устанавливается значение стейта компонента Form.
